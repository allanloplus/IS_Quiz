# Allan'S IT知識測驗

給 ISMS 從業人員、資安顧問、稽核員，以及想學資安 IT 基本功的人使用的測驗與學習網站。
講師：Allan顧問｜AI 小助理：阿拉蕾

- **110 題中英雙語題庫**：標準 30 題（STD-01～30，還原自「IS 專業 30 題」PDF 的英文原題，中文重新以專業 IT 用語翻譯）＋ AI 生成 80 題（AI-01～80）
- **9 大知識領域**：網路與基礎架構、作業系統與伺服器、虛擬化與雲端運算、容器化與 DevOps、軟體開發與程式設計、資訊安全、資料庫與大數據、IT 服務管理與維運、人工智慧與 AI 治理
- 題目以英文為主，可按「題目中文說明」看繁體中文；作答後的解說與檢討都附**題目中文翻譯、中文解說、英文解說、ISO/IEC 27001:2022 附錄 A 對應控制措施**與「Allan 顧問稽核小叮嚀」
- **通過門檻 ≥ 90 分**，通過後自動產生含測驗日期（民國與西元）與證書編號的通過證明，可下載 PNG 或列印

## 玩法

| 模式 | 說明 |
|---|---|
| 經典測驗 | 標準 30 題／AI 生成 80 題／隨機（10–100 題）／依類別（可複選）。可選「即時解說」或「交卷後檢討」，可打亂題目與選項順序 |
| 環島闖關 | 9 大領域對應 9 個台灣車站：台北101 → 桃園 → 新竹 → 台中 → 彰化 → 日月潭 → 台南 → 高雄港 → 玉山。每站 ≥90 分才蓋紀念章並解鎖下一站，全部通過另有「環島制霸證明」 |
| 夜市搶答 | 每題 45 秒、3 杯珍奶生命值、連擊加分、答對換夜市小吃；正確率 ≥90% 一樣產生通過證明 |
| 練習模式（免登記） | 經典測驗與夜市搶答都可切換成「練習模式」；首頁的「免登記練習」與車站的「免登記練習本站」也能直接進入。不需領車票、不填任何個人資料、不產生證明，成績不存入學習紀錄，只有答錯的題目會記入本機錯題本 |
| 知識圖書館 | 110 題完整解答與解說，可依來源、類別、關鍵字篩選；錯題本與錯題重練 |
| 今日一題 | 首頁每天換一題，直接作答 |

要取得通過證明的「正式測驗」，學員要先「領取環島車票」：公司／學校、職稱／身分、姓名、Email、我的目標（很厲害的資安人員／資安顧問／資安稽核員，或自行輸入）。沒有車票時按下正式測驗，網站會詢問要領取車票，還是改用練習模式。

## 個資與資料保存

網站是純靜態頁面，沒有後端。學員資料、成績、紀念章、錯題本與證明都只存在學員自己瀏覽器的 `localStorage`（鍵名 `ait.*`），不會傳到任何伺服器。填寫資料時會顯示依《個人資料保護法》第 8 條的告知事項並要求勾選同意；「我的學習」頁面可修改、匯出（JSON）或刪除全部資料。

因為證明是在學員端產生，它是學習成果紀錄，不是第三方驗證的證照。若之後需要由講師集中收集成績或驗證證書編號，需要另外加一個後端（例如表單或資料庫）。

## 本機預覽

```bash
python3 -m http.server 8000
# 瀏覽器開啟 http://localhost:8000
```

直接雙擊 `index.html` 也能開，但部分瀏覽器對 `file://` 的限制較多，建議用上面的方式。

## 部署到 GitHub Pages

1. 將此分支合併到 `main`
2. GitHub 儲存庫 → Settings → Pages → Build and deployment → Source 選「Deploy from a branch」
3. Branch 選 `main`、資料夾選 `/ (root)`，儲存
4. 約一分鐘後即可在 `https://<帳號>.github.io/<儲存庫名稱>/` 使用

## 修改或新增題目

每一題的格式（`js/questions-*.js`）：

```js
{
  id: "AI-81", src: "ai", cat: "sec", lv: 2,      // 來源 std / ai；類別 id 見 data.js；難度 1–3
  q: "English question",  qz: "中文題目",
  o: ["A", "B", "C", "D"], oz: ["甲", "乙", "丙", "丁"],
  a: 1,                                            // 正確答案索引（0 = A）
  ez: "中文解說", ee: "English explanation",
  iso: ["8.24"],                                   // ISO/IEC 27001:2022 附錄 A 編號，需在 data.js 的 iso 中存在
  tip: "稽核小叮嚀（可留空字串）"
}
```

改完後執行 `node tools/export-questions.js` 更新 `docs/question-bank.md`。

## 人工智慧與 AI 治理類別

第 9 類（台南站・南部科學園區）共 11 題：STD-08，加上 AI-71～AI-80。涵蓋機器學習類型、生成式 AI 幻覺、檢索增強生成（RAG）與權限、間接提示注入、資料投毒、影子 AI 與資料外洩、ISO/IEC 42001、EU AI Act 風險分級、NIST AI RMF，以及稽核 AI 系統時應看的證據。

## 標準 30 題的答案判定

原 PDF 沒有附解答，正確答案是依題意與業界通行觀念判定，並在解說中說明其他選項為何不選。下列幾題的選項彼此接近，建議講師再確認是否符合原出題方的答案：

- **STD-01**：選 MongoDB（Cassandra 也是資料庫，但屬特殊大規模情境）
- **STD-13**：選 IAST（部分 SAST 工具也能找出記憶體洩漏）
- **STD-20**：選 AEAD（若原題意偏向公開金鑰加密，可能是 PKI）
- **STD-23**：選 IaaS（各種雲端服務模式都有責任共擔）

若要更改答案，只要修改該題的 `a` 欄位與解說文字即可。
